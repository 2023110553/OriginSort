# OriginSort 개발 계획

OriginSort의 목표는 동국대학교 eClass에서 받은 파일을 사용자가 이미 정리한 과목 폴더로 안전하게 보내는 것입니다. 출처를 확인할 수 없거나 규칙이 충돌하면 파일을 그대로 둡니다.

## 1. 출처 분석 — 완료

- NTFS `Zone.Identifier` 읽기
- `ReferrerUrl`, `HostUrl` 추출
- eClass `ubboard` 자료실 ID 정규화
- 기존 폴더에서 출처와 목적지 관계 발견
- 실제 사용자 폴더 29개 파일, 6개 출처 검증

## 2. 규칙과 판별 — 완료

- SQLite 스키마와 로컬 데이터 위치 정의
- 발견한 규칙 미리보기 및 명시적 저장
- 저장된 규칙 조회와 활성화 상태 관리
- 기존 파일 하나의 예상 목적지 판별

완료 조건: 실제 eClass 파일을 입력하면 저장된 규칙에 따라 목적지를 출력하고 파일은 변경하지 않는다.

## 3. 안전한 이동과 복구 — 완료

- 기본 동작은 미리보기
- 명시적 실행 시에만 파일 이동
- 파일 잠금, 대상 폴더, 중복 이름 확인
- 이동 기록 저장
- 수정 여부를 확인한 안전한 되돌리기
- 다른 드라이브 이동 시 복사 결과 검증

완료 조건: 테스트 폴더에서 이동과 되돌리기가 데이터 손실 없이 왕복한다.

## 4. 다운로드 감시 — 완료

- Downloads 폴더 감시
- 임시 파일과 부분 다운로드 제외
- 파일 크기 안정화 및 잠금 해제 대기
- 이벤트 중복 방지와 누락 보완 스캔
- 자동 이동 ON/OFF

완료 조건: Chrome 다운로드 완료 후 승인된 규칙만 한 번 실행된다.

## 5. Windows 데스크톱 UI — 완료

- 첫 실행 폴더 분석
- 규칙 후보 확인 및 저장
- 최근 분류와 보류 사유 표시
- 자동 정리 ON/OFF
- 이동 기록과 되돌리기
- 시스템 트레이

완료 조건: 터미널 없이 최초 설정부터 자동 정리와 되돌리기까지 수행할 수 있다.

## 6. 배포 — 진행 중

- PyInstaller 단일 사용자 빌드
- Windows 시작 프로그램 등록 선택지
- 새 Windows 계정에서 설치 및 제거 검증
- 개인정보와 진단 로그 문서화

완료 조건: 개발 도구가 없는 Windows 10/11에서 설치하고 실행할 수 있다.
